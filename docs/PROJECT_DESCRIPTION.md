# Healthcare Analytics

## 1. Project Title

Healthcare Analytics – Doctor Visits Data Analysis

## 2. Introduction

This project analyzes a healthcare doctor-visits dataset to identify
patterns related to patient demographics, healthcare utilization,
health conditions, healthcare access and chronic conditions.

## 3. Objective

The main objectives are:

- Understand the healthcare dataset
- Analyze patient demographics
- Study doctor visit patterns
- Analyze age, income, health and illness
- Examine healthcare access indicators
- Analyze chronic-condition indicators
- Identify relationships between variables
- Present findings through interactive visualizations

## 4. Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Flask
- HTML
- CSS
- JavaScript

## 5. Main Features

- Interactive dashboard
- Data understanding
- Data preprocessing
- Statistical analysis
- Data visualizations
- Automated insights
- Healthcare AI assistant
- Dataset-based question answering

## 6. Project Architecture

Frontend → Flask Backend → Python Analytics → Dataset

## 7. Limitations

The project describes patterns in the available dataset.
It is not intended to provide medical diagnosis or treatment advice.
