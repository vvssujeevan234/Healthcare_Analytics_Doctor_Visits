# Data Analysis

## 1. Dataset Overview

The dataset contains healthcare-related records involving
patient demographics, doctor visits, health, illness,
income, healthcare access and chronic conditions.

## 2. Important Variables

| Variable | Description |
|---|---|
| age | Patient age |
| gender | Patient gender |
| visits | Recorded doctor visits |
| income | Income value |
| health | Health value |
| illness | Illness value |
| nchronic | Chronic-condition indicator |
| lchronic | Long-term chronic-condition indicator |
| private | Private healthcare indicator |
| freepoor | Free/poor healthcare indicator |
| reduced | Reduced-activity indicator |

## 3. Data Analysis Process

1. Load the dataset
2. Inspect the dataset
3. Check data types
4. Check missing values
5. Check duplicate records
6. Perform descriptive statistics
7. Analyze demographic variables
8. Analyze healthcare visits
9. Analyze health and illness
10. Analyze healthcare access
11. Analyze chronic conditions
12. Study relationships between variables
13. Create visualizations
14. Generate conclusions

## 4. Statistical Analysis

The project calculates:

- Record count
- Mean age
- Mean visits
- Mean income
- Mean health
- Mean illness
- Minimum values
- Maximum values
- Gender distribution
- Chronic-condition counts
- Healthcare-access counts

## 5. Visualizations

The project can include:

- Bar charts
- Histograms
- Pie charts
- Box plots
- Scatter plots
- Correlation analysis

## 6. Analytical Questions

- What is the average patient age?
- What is the average number of doctor visits?
- Which gender is most represented?
- What is the highest visit value?
- What is the illness distribution?
- How many records have chronic-condition indicators?
- How many records have private healthcare indicators?
- How many records have reduced-activity indicators?
